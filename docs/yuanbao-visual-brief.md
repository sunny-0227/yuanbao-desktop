# 元宝视觉设计简报

## 角色依据

元宝是项目作者饲养的长毛金虎斑猫。照片包含幼猫和长大后的状态，主形象以长大后的照片为准。

需要保持的特征：金棕色长毛、额头深色M形虎斑纹、浅奶油色嘴边和胸腹、绿色眼睛、蓬松围脖、粗大蓬松尾巴及深色尾端。照片中的伊丽莎白圈、家具、床品和其他生活物品不属于角色设定。

主要参考照片（原文件保持不变）：

- `253b43043426f6177e72ccd3896042de_compress.jpg`：成熟面部、耳朵和毛色。
- `b53537f3fda7d9b4aa033b1884e695d5_compress.jpg`：绿色眼睛和蓬松围脖。
- `64a1070ceebfefc553b468c32f93c623_compress.jpg`：身体比例、大尾巴与腹部毛色。
- `d96a63b0aa0ff7164f39654dc06b4a70_compress.jpg`：睡眠状态、奶油色胸腹与爪子。

## Logo候选方向

根据 [ip-as-logo skill](https://github.com/s1dashu/ip-as-logo-skill) 的流程，先确定三个方向，再生成六张独立方形候选，每个方向两张，分别从左下和右下探出。

| 方向 | 产品联系 | 主要形状 |
|---|---|---|
| A 圆脸探头 | 随叫随到的桌面助手 | 蓬松圆脸和双耳，重点简化额头虎斑识别特征 |
| B 围脖抱尾 | 温暖、可靠的陪伴 | 大头、蓬松围脖与收拢的大尾巴形成紧凑轮廓 |
| C 慵懒守候 | 安静驻留，需要时响应 | 坐着或趴着的元宝，柔和的眼睛和圆润身体 |

候选命名：A1/A2、B1/B2、C1/C2。Logo使用极简轮廓与少量大色块；不直接复制照片里的细毛、胡须与全部纹路。各张保留原始生成结果，选定后再按明确要求做导出或细化。

## 桌宠素材

桌宠与Logo共享角色身份，但不是同一套文件：桌宠保留真实毛色与关键纹路，输出无环境背景的完整角色，统一画布、基线与比例。

计划状态：`idle.png`、`listening.png`、`thinking.png`、`speaking.png`、`working.png`、`sleep.png`。先确立角色基准，再基于同一基准做状态变体，避免每张变成不同的猫。

工具：内置imagegen用于基于照片生成与编辑。提示词、参考图、输出尺寸和文件位置随实际生成结果记录；六张Logo候选已生成并保存在 `assets/brand/logo-candidates/`，提示词与生成记录随文件保存；已选定B2，应用图标与六个静态桌宠状态已接入，界面配色也采用同一品牌色。

## 已选定方案

B2为正式角色基准：`assets/brand/selected/logo.png`。品牌色为深青绿#315D59、金焦糖#C98A3A、暖奶油#F5E3B9；深浅主题的语义色在`ui/brand.py`。PNG原生图保留，ICO仅作Windows图标格式导出。
