# Windows 验收步骤

核心测试可在macOS上使用隔离数据执行；Windows界面、设备和系统控制需要在Windows 10/11验收。核心测试通过不能替代整机验收。

## 自动检查

```bat
.venv\Scripts\python -m pip install -r requirements-dev.txt -r requirements-win.txt
.venv\Scripts\python -m pytest -q
.venv\Scripts\python scripts\smoke_windows.py
.venv\Scripts\python -m ruff check app services ui main.py scripts tests
```

Windows UI结构检查创建工作台/设置/占位形象/提醒，渲染浅色和深色布局，不调用系统操作或录音。CI已配置这些命令和核心构建；只有实际执行成功后才可认定Windows验证通过。

## 核心交互

1. 首次启动显示工作台和占位形象。关闭工作台后托盘仍可打开；重复启动提示已有实例；退出后没有残留实例锁或后台Python进程。
2. 修改主题、字号、快捷入口、截图目录、CPU阈值后立即生效；退出再打开保持设置。复制exe到新目录不会把旧用户配置覆盖。
3. 配置支持tools/tool_calls的AI模型，检查“测试连接与工具调用”、连续追问、历史恢复、删除会话。文本聊天接口如果不支持工具调用，应明确提示。无密钥/401/429/断网不得假装完成操作；已有副作用后不得切换接口重放。请求途中停止后可以重新发送。
4. 输入“取消静音”应恢复音量，“不要截图”“解释一下锁屏”不能执行系统操作。清空回收站/关机等确认框默认选择“不”，取消后没有副作用。
5. 新增“十分钟后”“明天下午3点”“每天18:30”“每周一9点”提醒；测试多个到期提醒、稍后10分钟、循环、关闭弹窗、用户完成、重启补提醒。非法日期必须报错，不能忽略日期改为今天。
6. 新增/编辑/删除笔记，重启保持；检查旧JSON只导入一次。备份用户目录再模拟只读/写入失败，界面不提示假成功，不删除原资料。
7. 拖动占位窗口到不同屏幕和边缘，检查收纳、展开、透明度、皮肤状态占位以及重启位置；拔掉副屏后窗口回到可见范围。
8. 连续输入“十分钟后提醒我”→“喝水”→“改成半小时后”，应补充内容并修改同一条提醒；切换会话后不沿用旧对象。“算了”清除待处理任务，不创建记录。更换话题后不能默默修改旧提醒。
9. 用自然说法请求打开自定义目录里的软件，多候选时选择第二个，再说“没有弹窗”“打开了吗”。检查应针对同一程序，不把这些话当成软件名；只有观察到进程/窗口才能报告对应状态。
10. 输入带引号、空格的完整exe/lnk路径，正序“打开路径”和倒序“路径打开”均应进入本地工具；快捷方式目标移动后报实际失败。退出旧版托盘进程再启动新版，窗口标题应显示2.1.1。

## 语音与系统功能

1. 安装可选依赖和模型后，测试在线ASR、Whisper本地识别、auto在线失败兜底、麦克风列表、30秒上限、用户停止与立即重录。
2. 测试Edge在线TTS与系统离线TTS；停止播报后不残留音频通道或临时文件。静音模式下不播报、不唤醒；关闭窗口/退出/休眠及时释放麦克风。
3. Vosk开启后测试自定义唤醒词；唤醒后进入录音；播报期间不能自身唤醒；省电/休眠停止监听，恢复后重新监听。
4. 正常打开软件、含空格的快捷方式参数、文件和文件夹；关闭软件应发送正常窗口关闭而不是强杀。测试不存在路径/未配置软件。
5. 测试音量、锁屏、媒体控制、回收站、定时关机与取消关机；先保存工作，再进行这些真实操作。
6. 高CPU需连续两次触发；恢复需低于阈值10个百分点且连续两次。手动休眠30秒后仍保持；白名单与黑名单冲突优先白名单；关自动休眠不能误唤醒手动休眠。

## 打包与资源占用

默认目录打包与单文件打包分别验证：中文/空格路径、非管理员账户、缺少素材、外置.env、持久化配置、旧数据迁移、单实例、退出、重新启动。语音版与本地识别版单独验证依赖、模型路径和子进程启动。

任务管理器记录首次启动、活跃待机、空闲省电、唤醒监听、一次Whisper识别、高负载休眠、模型释放后的CPU/内存。不要在没有实测前宣称具体降耗百分比。签名与杀毒拦截需要真实Windows发布环境及证书。

## 2.1.1 回归

- 连续询问“你是AI吗”，能力介绍、条件句和引用“已打开”不能触发无执行记录提示；模型直接声称已经执行仍需回执。
- 将软件快捷方式改名，检查原软件名、exe名称及文件描述名称仍可找到同一实际目标；同名不同位置仍需选择。
- 注册安装目录内的套件子程序应按各自身份被识别；缺少元数据、无法读取目录时不能猜测路径。
