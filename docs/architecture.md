# 架构与实现边界

元宝采用Python + PySide6开发，目标平台是Windows 10/11。界面、业务协调和平台操作分别管理，语音依赖与模型按需加载。

## 模块分工

| 目录 / 模块 | 职责 |
|---|---|
| `main.py` | 启动、单实例锁、信号连接、退出清理 |
| `app/controller.py` | 会话、任务、音频和功耗状态的协调 |
| `app/config.py` | 配置声明、校验、旧字段兼容、环境变量优先级 |
| `app/app_context.py` | 区分打包只读资源与可写用户目录 |
| `app/storage.py` | 原子JSON写入、SQLite事务和旧数据迁移 |
| `services/command_router.py` | 明确指令的确定性识别，过滤否定、解释和引用 |
| `services/local_command_executor.py` | 有限业务任务队列、取消令牌、Qt结果信号 |
| `services/audio_service.py` | 录音、识别、播报与唤醒的互斥和生命周期 |
| `services/auto_sleep_service.py` | 非阻塞采样、功耗切换和恢复迟滞 |
| `ui/` | 工作台、设置、提醒弹窗、悬浮窗口与托盘 |
| `tests/` | 核心回归、线程通知、音频生命周期和Windows界面检查 |

## 数据与线程

笔记、提醒、会话与缓存使用SQLite事务；用户配置采用同目录临时文件加原子替换。写入失败传递给调用方，不能先显示保存成功。旧数据迁移不删除原文件，事务成功才记录迁移标记。

Qt对象和控件由主线程管理。业务任务、音频管线与低频资源采样使用独立受控队列，后台只发送信号。Windows COM在实际工作线程初始化与释放，Win32窗口句柄使用对应的64位签名。

每个任务都有独立ID和取消令牌。网络请求取消后，新任务可以进入队列；切换会话不会接收旧任务结果。已经发生的本地操作不能撤回，需要确认的指令在获得确认前不会执行。

## 语音与模型

录音与播报互斥，语音唤醒在录音、播报、任务执行、省电和休眠时暂停。临时WAV在识别结束后删除，临时MP3在播放通道关闭后删除。

Whisper在短生命周期子进程中完成转写；取消、超时或完成后结束进程。Vosk仅在开启唤醒时加载。程序不会自动下载模型。Edge-TTS需要联网，系统TTS提供离线播报。

AI客户端兼容Chat Completions，支持流式内容、上下文、备用接口和用户配置的本地模型服务。备用接口用于请求故障切换，不能替代服务商的统一余额查询；外部模型服务的安装与内存管理由用户负责。

## 功耗与桌面形象

手动休眠与自动休眠分开。CPU连续两次超阈值或命中黑名单后自动休眠，恢复需要负载降到阈值以下10个百分点且连续两次。休眠暂停音频与提醒弹窗，保留30秒守护检测以便恢复。空闲时不启动流式刷新计时器，没有待办时不轮询提醒。

托盘与UI目前同属一个进程。形象容器支持拖动、边缘收纳、透明度和位置记忆，默认加载B2衍生的六个透明PNG状态与六套动作序列；按实际显示尺寸缓存，保持宽高比。`app/pet_animation.py`读取和校验各动作元数据，管理正反播放边界；UI通过单次QTimer按12fps推进，切换状态复位帧索引。同一状态的重复通知不会延后正在运行的计时器。待机、聆听、思考、播报和执行状态播放动画，回到起点后分别停顿4000/600/1000/0/800ms。隐藏、收纳和休眠停止计时；休眠只显示其序列首帧。动画采用跨状态合计16帧LRU缓存，缺帧或无效元数据回落静态图。缺图回落默认皮肤或占位标记。品牌语义色由`ui/brand.py`统一管理。
