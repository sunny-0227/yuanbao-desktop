# 元宝桌宠素材

默认皮肤以选定的B2为角色基准，六个透明PNG位于 `default/`：`idle`、`listening`、`thinking`、`speaking`、`working`、`sleep`。

每张1254×1254，保留内置生图工具的原始输出。状态提示词和元数据在 `prompts/`，各状态参考同一张待机基准以保持身份。运行时按窗口尺寸缓存，避免高分辨率贴图全部常驻。

六套动作分别位于 `default/{state}-animation/`，每套59帧，480×480，12fps。源视频由作者通过 JoyAI 生成，去掉开头4帧、按各视频蓝底分别抠图并增加透明留白。处理参数与源文件校验值见各目录的 `metadata.json`；可用 `scripts/prepare_pet_animation.py` 复现，原视频不随软件打包。

| 状态 | 源视频 | 回到起点后停顿 | 运行方式 |
|---|---|---|---|
| idle | joyai_video_2026-10-14_169970.mp4 | 4000ms | 待机眨眼与摆尾 |
| listening | 聆听.mp4 | 600ms | 聆听动画 |
| thinking | 思考.mp4 | 1000ms | 歪头与眨眼 |
| speaking | 播报.mp4 | 0ms | 嘴部开合，不与语音逐字同步 |
| working | 执行任务.mp4 | 800ms | 抬爪与收回 |
| sleep | 休眠.mp4 | — | 运行时只显示首帧，呼吸素材可在预览页单独播放 |

五种活动动画正放再倒放回到原位，按上表停顿后重复。隐藏、边缘收纳和休眠时停止播放；切换状态从对应动作首帧开始，只缓存跨状态最近16张显示尺寸的帧。缺失或损坏素材回落静态图。其他皮肤缺图时使用默认静态素材。完整说明见 [素材说明](../../docs/asset-requirements.md)。
